- Program ini memuat dua library java yakni scanner untuk menerima input dan hashmap untuk menyimpan data berdasarkan key and value layaknya dictionary pada Phyton, program ini memanfaatkan method/fungsi konversi yang berisi objek dengan key nilai huruf dan value bobot nilai dalam angka, dalam main dengan try catch untuk menangani error, lalu perulangan for dengan auto increment serta indeks yang dimulai dari nomor 1 lalu keadaan untuk menjalankannya ketika i <= jumlah MK yang berisi program untuk meminta input data nama mata kuliah, nilai, bobot sks, dengan kondisi jika bobot nilai sebagai objek memuat key layaknya input nilaiHuruf maka bobot akan di ambil berdasarkan hashmap tadi.
- Ada juga baris yang akan menghasilkan nilai mutu (hasil kali bobot dan sks) dengan tipe data double yang akan bertambah dengan nilai mutu itu sendiri, seiring nilai mutu dieksekusi sesuai perulangan yang dilakukan java (berdasarkan input jumlah mata kuliah) dan disimpan ke dalam variabel total nilai mutu, begitu juga dengan total sks yang terus bertambah dengan inputan yang dimasukkan pengguna dan disimpan ke dalam variable total sks
- Tidak lupa kunci utama program ini untuk menghitung IPS Semester yang merupakan hasil bagi dari total nilai mutu dan juga total sks, dan untuk hasil cetak yang sesuai digunakan printformat dengan format %.2f%n (maksimal 2 angka dibelakang koma, dengan tipe data float)
